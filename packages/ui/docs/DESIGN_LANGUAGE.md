# ARTINOS UI design language

**Character:** adaptive high-density professional UI; precision instrument rather than website form.

## MetaComp

The Continuous Instrument Row remains the flagship dense presentation.

- 1 parameter concept → 1 MetaComp.
- Normally 1–2 primary manipulation surfaces.
- Rounded rectangle first, softened second; never default pill/lozenge geometry.
- Slider/Range use full-surface material division and seam handles, not a thin inner track + circular thumb.
- Surface may carry useful ticks, detents, gradient, range span, graph, vector state, automation/modulation or value information.
- Controlled composition families: full, paired, segmented, visual, utility, hero, compact, micro, focus.
- Recompose rather than shrink.

## Interaction arc

```text
quiet → proximity → contact → manipulation → precision/snap → release → settle → quiet
```

Slow/off-axis manipulation can increase precision while fast motion remains efficient. Parameter state stays exact; visual pose may remain expressive.

## Material

Neutral material first: Optical Frost, Graphite Studio, Stone, Smoked Bronze, Monolith and Light Stone. Accent behaves as signal/energy, not decorative coloring.
