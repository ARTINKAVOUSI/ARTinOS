# Component coverage

## Primitive / common UI

Button, IconButton, SearchField, Tabs, Checkbox, RadioGroup, Popover, Dialog, Menu, Tooltip.

## Instrument / MetaComp controls

Slider, Range, Number, Scrubber, Knob, Toggle, Segmented, Select, Text, Color, Gradient, Vector, XY, Meter and Action.

## Composite

Schema-driven Inspector plus machine-readable ComponentRegistry.

The package is intentionally registry-based: one Parameter can resolve to different presentations based on context/density rather than being permanently mapped to one widget.
