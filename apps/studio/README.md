# ARTINOS Studio

Integration application that recreates the reference composition using the two independent packages:

```text
@artinos/metablock → workspace / posture / floating / docking / spatial intent
@artinos/ui        → ParameterGraph / MetaComp / schema / controls / design language
```

## Working surfaces

- fullscreen material stage
- adaptive bottom/left/right command dock
- Scene / Material / Render / Bake inspectors
- full-surface Slider/Range and other MetaComp controls
- quick Workspace posture/world control
- stable direct-manipulation MetaBlocks with regroup/dock/split/float behavior
- right-click MetaBlock context menus with package-owned capabilities
- separate ARTINOS System Editor
- live material-world editor
- MetaComp geometry/density editor
- MetaBlock curvature/Dock Field/snap/MetaBlend editor
- motion/physics editor
- typography/contrast editor
- component library lab
- live JSON schema → production MetaComp workbench
- accessibility/adaptation controls
- config export
- parameter undo/redo
- local state persistence

Keyboard:

- `Ctrl/Cmd + K` search controls
- `E` open System Editor
- `Esc` close editor / cancel search context
- `Ctrl/Cmd + Z` undo parameter edits
- `Ctrl/Cmd + Y` redo
