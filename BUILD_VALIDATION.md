## Correct reference hierarchy verified

```text
LOCKED FULLSCREEN VIEWPORT METABLOCK
│
└── COMMAND DOCK METABLOCK  (persistent parent / home zone)
    ├── Scene     MetaBlock(role=panel)
    ├── Material  MetaBlock(role=panel)
    ├── Render    MetaBlock(role=panel)
    └── Bake      MetaBlock(role=panel)
```

The viewport is the only permanently fullscreen surface. The command Dock remains a bounded parent MetaBlock layered over it. Child panels belong to that Dock by default and are not represented as root fullscreen regions.

## MetaBlock state-transition corrections verified

- `dockBlock(block, { area:'center', targetGroupId:null })` is rejected for ordinary leaf/panel MetaBlocks. A child panel cannot accidentally become a root-center fullscreen dock.
- `resolveWorkspaceRects()` ignores invalid extracted/panel root-center nodes instead of giving them the remaining full Workspace rectangle.
- `repairSpatialState()` repairs stale/legacy root-center detached panels into bounded preferred floating geometry.
- `repairSpatialState()` also restores persistent Dock MetaBlocks to their declared `homeZoneId` / `homeZoneMode` when saved state is invalid.
- The command Dock declares itself as a persistent tab container and remains in its viewport Workspace Zone; its children detach independently.
- Scene / Material / Render / Bake declare explicit preferred floating geometry, so a drag-out does not inherit the large Dock or viewport dimensions.
- Dragging an already docked single-panel MetaBlock morphs toward that preferred floating geometry while preserving direct pointer control.
- Releasing on an **unarmed** Workspace-edge guide calls snap behavior and keeps the MetaBlock floating.
- Holding in a sufficiently strong/stable Dock Field arms structural docking; only the armed release changes topology.
- Dock-role targets are merge/attach targets. Their body does not become a directional split target merely because the pointer is close to an internal edge.
- The remembered parent/tab index is used for exact return-home.
- After a panel is deliberately regrouped into another stable Dock/Group, the old return state is cleared so the new parent becomes its next natural home.
- Small accidental movement over the source group does not detach the panel.
- Explicit maximize promotes only the leaf MetaBlock over the locked viewport. Accidental tab double-click maximize is not part of the default interaction.

## Context menu verification

Action semantics are generated by `@artinos/metablock`; visual presentation is supplied by `@artinos/ui`.

The menu is relationship-aware and can expose:

- Rejoin / Attach Back to remembered parent;
- Detach from current parent at preferred floating size;
- compact 2×2 **Snap** actions that keep the panel floating;
- compact 2×2 structural **Dock** actions;
- Attach to another Dock;
- Group / Merge with an ordinary MetaBlock group;
- Reset Floating Size;
- Pin / Auto-hide;
- explicit Maximize / Restore;
- Pop Out;
- Close, when capabilities allow it.
